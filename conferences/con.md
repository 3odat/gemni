## 4) Suggested tailoring by venue (1–2 sentence pitch)

- **USENIX Security / VehicleSec:** emphasize *system-level* vulnerability in RAG memory pipelines for multi-agent autonomy, a clear threat model (query-level access), and measurable physical-world impact + defenses.

- **WOOT:** emphasize *attack methodology*, reproducible exploitation pipeline, and practical adversary workflow (how an attacker reliably causes unsafe behaviors).

- **SIGCOMM / ICCCN:** emphasize multi-agent UAV networking + edge comms context; how memory retrieval influences distributed decision-making and how adversaries exploit it.

- **HPDC:** emphasize distributed state/memory as a first-class systems component; performance/robustness tradeoffs and secure retrieval protocols.

- **IEEE Cloud Summit:** emphasize cloud/edge deployment and engineering practicality; lightweight mitigations and deployment constraints.
